# Getting help

This is where to ask about any repository of [humanfia](https://github.com/humanfia) that has no
SUPPORT.md of its own.

## Look first

Most questions are answered already, and these answer faster than a person can:

- The repository's README: what it is, how to run it, and where its documentation is.
- [The documentation](https://docs.humanfia.ai/), for the projects that have it, such as
  [humanize](https://docs.humanfia.ai/humanize/).
- The repository's issues, open and closed: someone may have asked before.

## Then ask

Open an issue on the repository the question is about.

| You have | Open |
| --- | --- |
| a question the docs did not answer | a blank issue, or the repository's Question form |
| something that does not work | a Bug Report |
| something you wish it did | a Feature Request |
| a vulnerability | nothing public: follow [SECURITY.md](SECURITY.md) |

## What to expect

Each repository is maintained by a few people, as well as they can. There is no paid support
and no promised response time. Only the latest `main`, and the latest release where there are
releases, is supported, so upgrade first and check the problem is still there.

Some questions are for someone else:

- signing in to a coding agent CLI, its billing, or its models: the CLI's vendor;
- a dependency of a repository, or third-party material it includes: its owner.
